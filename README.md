# بوت سوريا

بوت تيليغرام خاصّ: لوحة مثبّتة بأرقام اليوم تتحدّث كلّ ساعة بلا إشعار، ونشرة واحدة كلّ صباح، وتنبيه حين يتغيّر سعرٌ فعلًا.
يعمل على GitHub Actions كلّ ساعة، بمكتبة بايثون القياسيّة وحدها.

المرحلة الأولى (الأرقام) تعمل. ومن المرحلة الثانية يعمل **الجامع الصامت**: يحفظ ما تنشره القنوات الرسميّة وسانا والصحف في `news/` دون إرسال، وينبّه على المراسيم والتعيينات، ويكتب موجز نشرة الصباح. السؤال والجواب والأدلّة تأتي بعد.

## الجامع الصامت (`news.py`)

- **المصادر** في `sources.json`: 68 قناة رسميّة في تيليغرام (تُقرأ من صفحة المعاينة العامّة `t.me/s`)، وخلاصات سانا والفداء والوطن وعنب بلدي. لكلّ مصدر درجة: 1 الجهة نفسها، 2 إعلام رسميّ، 3 إعلام خاصّ.
- **الأرشيف:** ملفّ لكلّ يوم `news/YYYY-MM-DD.jsonl`، سطر لكلّ منشور (المصدر، الدرجة، الوقت، العنوان، النصّ، الرابط). يُحتفظ بستّين يومًا.
- **لا يُرسل منه شيء** إلّا: تنبيه «⚖️» حين يصدر مرسوم برقمه أو يُعيَّن وزير أو محافظ (مرّة واحدة للمرسوم مهما تعدّدت القنوات)، وموجز «يخصّ حماة» و«أهمّ ما صدر في سوريا» في نشرة الصباح.
- **الموجز** يكتبه Gemini من منشورات المصادر الرسميّة في آخر 24 ساعة، وكلّ بند بروابط مصادره. يحتاج السرّ `GEMINI_API_KEY`، وإن غاب أو تعذّر خرجت النشرة بلا موجز.

## القواعد

- **التضارب:** إن ذكر أحد المصدرين سعرًا جديدًا ولم يوافقه الآخر، بقي الرقم المعتمد وأُرسل «⚠️ غير مؤكَّد» مرّةً واحدة. حين يتّفقان يُرسل «🔔 تغيّر سعر».
- **تنبيه الدولار والذهب:** عند تغيّرٍ يبلغ 2% قياسًا بآخر قيمةٍ نُبّه عليها، وعند كلّ نشرةٍ رسميّة تغيّر سعر الدولار.
- **تعطّل مصدر:** يُعرض آخر ما قُرئ منه. بعد ثلاث ساعاتٍ متتالية يصل تنبيهٌ واحد، ثمّ تنبيه العودة.
- **النشرة:** أوّل نبضةٍ بعد السابعة صباحًا بتوقيت دمشق، مرّةً في اليوم.

## الإعدادات (`config.json`)

- `city`, `lat`, `lon`: المدينة وإحداثيّاتها (للطقس).
- `prayer`: المسجد (`mosque`)، ورقمه في «مسجدك» (`mosque_id`)، وإحداثيّاته، وطريقة الحساب (`method`: `null` = التلقائيّة للبلد).
- `bulletin_hour`: ساعة النشرة. `move_pct`: نسبة تنبيه الدولار والذهب. `basket_pct`: نسبة ما يُذكر من تغيّرات السلّة.

## التشغيل

السرّان في Settings ← Secrets and variables ← Actions: `TELEGRAM_TOKEN` (رمز البوت من BotFather) و `TELEGRAM_CHAT_ID` (رقم محادثتك).
قبل إضافتهما لا يفعل المستودع شيئًا. بعدها يبدأ خلال ساعة، أو فورًا من Actions ← syriabot ← Run workflow.

المستودع يجب أن يبقى **عامًّا**: مؤقّت الانتظار في البيئة `wake-60` (60 دقيقة) لا يعمل في المستودعات الخاصّة على الخطّة المجّانيّة.

## التجربة على الحاسوب

```
python syriabot.py --dry out          بلا تيليغرام: يكتب الرسائل والحالة في المجلّد out
python tests/t_syriabot.py            اختبارات القارئات والقواعد بلا شبكة
python tests/t_news.py                اختبارات الجامع الصامت بلا شبكة
python tests/t_syriabot.py --save     يحدّث نسخ الصفحات المحفوظة للاختبار
```

المجلّدات `archive/` و `sources/` و `local/` محلّيّة لا تُرفع: أرشيف المنشورات، وسجلّ المصادر، وما يخصّ الحيّ.
